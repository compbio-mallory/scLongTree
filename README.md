# scLongTree simulation utilities

This directory contains the simulation utilities originally distributed with scLongTree.

## Files

- `gen_tree.py`  
  Generates longitudinal clonal trees for a specified number of timepoints and evolutionary parameters.

- `sim_par.py`  
  Simulates cells and mutations on the generated tree and produces the matrices used as input to scLongTree. Simulation parameters include false positives, false negatives, missing observations, mutation rate, and other evolutionary settings.

- `GT_getSNVrelations.py`  
  Extracts ground-truth SNV relationships from simulated trees for downstream evaluation.

- `annotateSimData_LACE.py`  
  Prepares simulated data for analyses involving LACE.

- `convertCSVToRData.R`  
  Utility for converting simulated data for downstream R-based analyses.

## Example workflow

### 1. Generate a longitudinal clonal tree

```bash
python simulation/gen_tree.py \
  -T 3 \
  -t_v 15 7 0 \
  -v1 0.2 \
  -v2 0.4 \
  -u 0.2 \
  -B 0.2 \
  -theta 0.2 \
  -o tree.csv
```

Parameters:

| Parameter | Description |
| --- | --- |
| `-T` | Number of timepoints. |
| `-t_v` | Values representing the sampling timepoints. Supply one value for each timepoint. |
| `-v1` | Condition variable controlling the distribution of mutations during tree generation. |
| `-v2` | Condition variable controlling the distribution of mutations during tree generation. |
| `-u` | Condition variable controlling the generation of unobserved subclones. |
| `-B` | Beta-splitting parameter used in generation of the clonal tree structure. |
| `-theta` | Condition variable controlling the assignment of new mutations to subclones. |
| `-o` | Output file for the generated ground-truth tree. |

For the example above, the simulator generates a tree with three timepoints using `15`, `7`, and `0` as the corresponding timepoint values and writes the tree to `tree.csv`.

### 2. Simulate single-cell mutation data

After generating the tree, use `sim_par.py` to assign cells and mutations and introduce sequencing errors:

```bash
python simulation/sim_par.py \
  -a 0.01 \
  -b 0.2 \
  -m 0.2 \
  -t 3 \
  -mc 1.7 \
  -f tree.csv \
  -P output_prefix
```

Parameters:

| Parameter | Description |
| --- | --- |
| `-a` | False-positive rate. |
| `-b` | False-negative rate. |
| `-m` | Missing-data rate. |
| `-t` | Number of timepoints. |
| `-mc` | Mutation-rate parameter used during simulation. |
| `-f` | Input ground-truth tree generated by `gen_tree.py`. |
| `-P` | Prefix, including an optional path, used for the generated output files. |

For example, `-a 0.01` specifies a false-positive rate of 0.01 and `-b 0.2` specifies a false-negative rate of 0.20.

The generated files contain the simulated genotype and observed mutation data together with information required for downstream scLongTree analysis and ground-truth evaluation.

## Ground-truth SNV relationships

`GT_getSNVrelations.py` can be used to derive ground-truth relationships between simulated SNVs for downstream evaluation.

These relationships include mutations that occur on the same lineage, ancestral/descendant relationships, and incomparable relationships according to the simulated ground-truth tree.
